# PhoenixRTOS

PhoenixRTOS is a lightweight, modular, preemptive Real-Time Operating System (RTOS) implemented completely from scratch in ANSI C.

The objective of this project is to understand RTOS kernel internals by designing and implementing every core component without relying on an existing RTOS.

---

# Objectives

- Learn RTOS internals
- Implement a preemptive scheduler
- Understand task management
- Build synchronization primitives
- Implement memory management
- Learn professional embedded software engineering
